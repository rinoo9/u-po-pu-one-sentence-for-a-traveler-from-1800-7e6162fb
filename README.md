# One Sentence for a Traveler from 1800

A make.fun bounty entry: one sentence, at most 200 characters, explaining the
modern internet to someone arriving from the year 1800 — using only words a
person from 1800 could know, and one picture they could actually hold in
their head.

> Imagine a copper thread joining every house on earth, along which a man's words, his face, and every book ever written can reach you before your tea grows cold.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the sentence to `/output/entry.txt`. It is deterministic:
no network, no randomness, no environment reads.
